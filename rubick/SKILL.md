# Rubick

当前请求已由用户明确交给 Rubick 处理。Rubick 是技能发现与路由入口：查询已连接服务当前提供的技能，判断哪些技能适用于这项任务，并在需要时读取对应技能的完整说明，再据此协助用户。

## 处理请求

先通过 Rubick API 查询当前在线技能列表，根据技能名称和说明判断是否有匹配项。列表只包含技能元数据；确定需要某项技能后，再请求该技能的完整正文，并遵循其中描述的接口和约束。在线技能 ID 带有 `rubick_` 前缀；详情接口会转发到提供该技能的服务。

如果没有匹配的在线技能，告知用户当前没有适用的 Rubick 技能，并根据已有能力继续协助。

## API 使用

使用服务地址访问下方 API。技能列表用于发现和筛选能力；技能详情用于获取选定技能的具体操作方法。
